# Production overlay

This overlay targets the hardened single-node k3s host documented in
[`deploy/host/k3s`](../../host/k3s). It applies the namespace, Pod Security
labels, a default-deny ingress policy, resource defaults, and a namespace
budget. Persistent services and application releases remain separate targets
so a foundation reconciliation cannot replace a database or publish a new
application image as a side effect.

Runtime Secrets are created only by the protected deployment workflow. No
Secret resource is generated by this overlay or committed to Git.
